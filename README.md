# Poliport Nakliyeci Portalı

Poliport kara yolu sevkiyatları için bağımsız portal tasarımının ilk sürümü.

Bu aşamada yalnızca karşılama ve genel bakış ekranı hazırlanmıştır. Firma ve
sürücü kayıtları, araç/evrak havuzu, sevkiyat talepleri, randevu/Pregate ve saha
girişi modülleri sonraki iterasyonlarda ayrı ayrı geliştirilecektir.

## Kapsam dayanağı

- Dökme sıvı yük depolama
- Kuru yük / genel yük
- A tipi antrepo

Kaynak: <https://www.poliport.com/sirket-profili.html>
